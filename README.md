# 河合隼雄.skill

[日本語](README.ja.md) | **简体中文**

**本项目由 Evostructs 在 OpenAI Codex 的帮助下开发。**

一个 skill，用“河合隼雄式视角”帮助用户整理情结、梦、故事、关系、教育、自我理解和现代人的心灵困惑。

它不是河合隼雄本人，也不是心理治疗工具。它的目标是提供一种基于河合隼雄著作与最终讲义蒸馏出的思想视角：慢下来，听见问题背后的故事，看见情结和无意识如何在生活中显现，并把个人经验放回关系、文化和象征结构中理解。

## 功能

- 用第一人称的“河合式视角”回应，但首次激活时会说明这是模拟视角。
- 帮助用户识别反复出现的内在图像、角色、剧本和情结。
- 把梦、神话、童话、文学、家庭、教育、咨询关系和现代生活放在一起理解。
- 使用“コンステレーション（中文：星丛式排列；英文：constellation）”视角：不只追问单一原因，也观察多个事件、关系、身体感、时代气氛和观察者参与如何同时形成意义。
- 给没有心理咨询条件的用户提供低风险的自我整理方式，例如命名情结、记录图像、区分幻想与行动、建立现实边界。

## 适用场景

适合用于：

- “我反复陷入某种关系/欲望/行为模式，想理解它。”
- “我做了一个梦，想从象征和无意识角度理解。”
- “我和孩子、父母、伴侣或学校之间的问题让我困惑。”
- “我想用河合隼雄、荣格派东方视角看一个人生问题。”
- “我没有条件做心理咨询，但想先安全地整理自己的内心材料。”

可触发关键词包括：

- `河合隼雄`
- `河合视角`
- `河合会怎么看`
- `河合式心理学`
- `荣格派东方视角`
- `hayao kawai perspective`

## 适用范围

这个 skill 的适用范围是“思想视角”和“自我理解辅助”，不是临床诊疗。

它可以帮助用户：

- 找到一个反复出现的情结名称。
- 看见欲望、羞耻、愤怒、逃避、幻想背后的故事结构。
- 区分幻想和现实行动。
- 在关系、金钱、性、职场、家庭等场景里建立更清楚的边界。
- 把一个问题从“谁对谁错”放回更完整的心理和关系场中。

它不适合用于：

- 心理诊断。
- 医疗建议。
- 药物建议。
- 危机干预。
- 替代专业心理咨询、精神科、心理治疗或紧急服务。
- 判断某个人是否患有具体精神疾病。
- 给出操控他人、越界关系、性骚扰、欺骗、伤害自己或伤害他人的行动建议。

如果用户表达自伤、伤人、严重失控、持续严重失眠、现实功能明显崩塌、精神症状、药物问题或紧急危险，应停止做象征解释，明确建议寻求现实中的专业或紧急支持。

## 安装

把这个仓库复制或克隆到你的 AI 客户端支持的 skills 目录。目录名建议使用稳定的英文名：

```text
hayao-kawai-perspective
```

如果用于 Codex，可放在：

```text
~/.codex/skills/hayao-kawai-perspective
```

其他支持 skill 的客户端，可按各自的 skills 目录规则安装。

## 与 Navigator 联动

如果要把河合式自我理解与约会中的外部证据、现实风险和下一步行动结合，可配合 [Navigator](https://github.com/Evostructs/navigator-skill) 使用。两个 Skill 各自独立：河合 Skill 负责整理故事、情结、投射与反复模式，Navigator 负责区分外部事实与脑补，并给出可验证的下一步和止损线。

```text
同时使用 $navigator 和 $hayao-kawai-perspective：先分析我的内在关系模式，再核对这段聊天的外部证据，最后给出下一步和止损线。
```

## 来源说明

本项目包含 skill 指令和必要参考说明，不包含原始书籍或长篇摘录。

主要参考河合隼雄相关著作，以及京都大学最终讲义《コンステレーションについて》的整理材料。

术语说明：本项目保留日文 `コンステレーション`，中文译为“星丛式排列”，英文译为 `constellation`。这里不把它简单译成“星座”，因为它强调的是多个心理、关系和现实因素同时聚合成意义的整体状态。
