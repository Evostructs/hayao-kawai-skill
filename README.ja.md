# 河合隼雄の思想に着想を得た内省支援 skill

**日本語** | [简体中文](README.md)

**このプロジェクトは、Evostructs が OpenAI Codex の支援を受けて開発しました。**

河合隼雄の著作や講義から整理した視点を手がかりに、コンプレックス、夢、物語、人間関係、教育、自己理解、現代を生きる人の心の悩みについて、急いで答えを出さずに考えるための skill です。

河合隼雄本人を再現するものではなく、心理療法、診断、医療行為を行うものでもありません。物事を一つの原因だけで説明せず、本人の語る物語、関係、文化、象徴、無意識の動きを一緒に見つめるための補助ツールです。

## この skill でできること

- 繰り返し現れる人間関係や行動のパターンを、コンプレックスや物語の観点から整理する
- 夢に現れたイメージを、予言や命令としてではなく、自己理解のための象徴として考える
- 神話、昔話、児童文学、家族、教育、心理臨床を横断しながら、一つの経験を多面的に見る
- `コンステレーション`の視点から、出来事、夢、関係、身体感覚、時代状況などが同時にどのような意味を帯びているかを考える
- すぐに専門的な相談を受けられない場合にも、現実との境界を保ちながら、心の材料をできるだけ安全に整理する

## こんなときに使えます

- 同じような関係、欲望、葛藤、失敗を何度も繰り返している
- 印象に残る夢について、象徴や無意識の観点から考えてみたい
- 親、子ども、パートナー、学校との関係を、正しさだけではない角度から見直したい
- 河合隼雄やユング心理学に着想を得た視点で、自分の経験を整理したい
- 心理療法の代わりではなく、まず自分で安全に内省するための手がかりがほしい

日本語では、たとえば次のように呼びかけられます。

- `河合隼雄の視点から一緒に考えてください`
- `河合隼雄ならどう考えるか、その思想を手がかりに整理してください`
- `ユング心理学と物語の観点から、この夢を考えてください`
- `このコンプレックスについて、結論を急がずに整理してください`

## 応答の方針

- 最初に、河合隼雄本人ではなく、著作から整理した視点による応答であることを明示します。
- 利用者が日本語で話した場合は、不自然な翻訳調を避け、自然で落ち着いた日本語で応答します。
- 診断名を付けたり、一つの象徴に決まった意味を押しつけたりしません。
- 夢や偶然を、予言、命令、超自然的な証明として扱いません。
- 現実の安全、他者の権利、医療上の必要性を、象徴的な解釈より優先します。
- 河合隼雄の発言を作り出したり、出典のない文章を本人の引用として示したりしません。

```text
河合隼雄の思想に着想を得た視点から、繰り返し見るこの夢について一緒に考えてください。
```



## インストール

このリポジトリを、利用する AI クライアントの skills ディレクトリにコピーまたはクローンします。ディレクトリ名には、次のような安定した英語名を推奨します。

```text
hayao-kawai-perspective
```

Codex で利用する場合の配置先：

```text
~/.codex/skills/hayao-kawai-perspective
```

その他の skill 対応クライアントでは、それぞれの配置方法に従ってください。

## 利用範囲と安全上の注意

この skill は、内省と自己理解を支えるためのものであり、次の用途には使用できません。

- 精神疾患や発達上の問題の診断
- 医療、服薬、心理療法に関する個別の指示
- 危機介入や緊急対応の代替
- 他者を操作する方法や、暴力、搾取、嫌がらせ、自傷・他害につながる助言
- 専門家による心理療法、精神科医療、その他の現実の支援の代替

自傷・他害のおそれ、著しい混乱、深刻な不眠、幻覚や妄想が疑われる状態、日常生活の大きな崩れなど、緊急性のある問題がある場合は、この skill による象徴的な解釈を中止し、医療機関や地域の相談窓口など、現実の支援につながってください。差し迫った危険がある場合、日本では救急・消防の `119` または警察の `110` に連絡してください。

## 参考となる考え方

本プロジェクトは、河合隼雄の著作と、京都大学最終講義「コンステレーションについて」に関する整理資料を主な手がかりとしています。原著、書籍本文、長い引用文は収録していません。

ここでいう `コンステレーション` は、単なる星座という意味ではありません。複数の出来事、夢、人間関係、身体感覚、時代の空気、観察する人自身の関わりが一つの布置をなし、全体として意味を帯びるあり方を指します。
